# THEADORO GIFT - Frontend (@theadoro/web)

Contexto específico para o frontend do marketplace.

## Tecnologias
- React 18 + Vite
- Tailwind CSS
- Shadcn UI
- Lucide React

## Padrões de Projeto
- **Páginas:** Localizadas em `src/pages/`, divididas por perfil (admin, seller, buyer).
- **Componentes:** `src/components/`, seguindo a estrutura de subpastas por funcionalidade.
- **Hooks:** Lógica de estado reutilizável em `src/hooks/`.

## Mandatos Específicos
- Sempre use TDD para novos componentes ou correção de bugs.
- Respeite os layouts definidos em `src/components/layouts/`.
